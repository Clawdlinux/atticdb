## Hand audit

Every non-errored row was read in full, pass and fail. 2 verdicts changed.

- **old-r2 H3, Copilot to Claude: grader fail, audited pass.**
  The reply says "Yes, it's allowed now" and cites STOR-5150 and plain files.
  It names the INC-2209 deadlock only as history. The grader read that as "still applies".
- **old-r2 H4, Claude to Copilot: real fail.**
  The reply says "No" and gives Python 3.9, but never names bramble-ci. That fails the plan's rule.
- **new H1, Claude to Copilot, both reps: capture miss, audited hit.**
  The capture regex only knew "412 bytes". The readers quote "412 B → 24 B" and "412-byte JSON vs. 24-byte".
  412 appears only in the H1 writer prompt. So the writer saved it in the store in a form the regex missed.
  This PR widens the regex to "412 B" and "412 vs 24 bytes", with tests.
  The store files weren't kept, so "same note as LEDG-7731" is inferred from the reply, not read.
- Old H1 and H5 rows stay misses. Their readers never quote 412.
  One says "No reason was ever written down".

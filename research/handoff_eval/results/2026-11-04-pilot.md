## Hand audit and diagnosis (2026-11-04)

1 rep per cell. This is an integration pilot, not a statistical result. Every failing or errored row was read by hand.

### Grader misses (corrected in the audit numbers below)
- H5 in all 4 arms, Claude writer to Copilot reader: "I couldn't find a recorded retention period ..." is a correct abstain. The marker list lacked "couldn't find".
- H4 files, Claude to Copilot: "No. HANDOFF.md requires Python 3.9 compatibility" ties 3.9 to the handoff. The grader only accepted 3.9 tied to CI, the runner or the repo.

### Strict by ruling (kept as fails)
- H3 files and H3 oracle, Claude to Copilot: the reader cited "the shared SQLite handle was removed", not STOR-5150 or plain files. The grader requires one of those 2 so a code-inspection yes can't pass.

### Errors
- H6, all 4 arms, Copilot writer to Claude reader: the Claude reader hit its session limit ("resets 6:10pm"). Another Claude Desktop session shares the same quota. Rerun these after the reset.

### What failed, by stage
- **Native memory doesn't cross tools.** In H4 native, Claude to Copilot, the Claude writer saved the rule to Claude's own memory (`MEMORY.md`, `bramble-ci`, `3.9`). The Copilot reader couldn't see it, so it answered "Yes" and failed. AtticDB exists to close exactly this gap.
- **atticdb arm: capture quality, not delivery.** Delivery was 9/9 through the sessionStart hook on both harnesses. The one atticdb fail, H1 Copilot to Claude, happened because the Copilot writer saved the ticket (LEDG-7731) but not the reason (412 vs 24 bytes). The reader rightly said the notes don't say why. So the stage that failed is "captured the decision but not its reason".
- **files arm: use.** In H1 files, Claude to Copilot, HANDOFF.md reached the reader, but the reader still gave a generic reason.
- **Abstain works.** No arm invented a retention period in H5.

### Gap to fix first
Capture quality: when an agent saves a decision, it should save the reason with its evidence (numbers, ticket ids, the constraint), and what changed when a decision is reversed. That's guidance in the MCP instructions, the tool descriptions and the chat-start block. It's not a storage change. Then rerun this exact matrix with the same model pins and compare.

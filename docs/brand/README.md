# AtticDB brand assets

The mark is a roof with a box kept under it. The roof is the attic. The box is what you stored.
Its colours come from atticdb.com: warm near-black #16110E, cream #EDE6D8 and lime #C8F03C.

| File | Use |
|------|-----|
| `atticdb-mark-reversed.svg` | Cream #EDE6D8 roof, lime #C8F03C box. On #16110E and other dark grounds. This is the mark on atticdb.com. |
| `atticdb-mark.svg` | #16110E roof, deep lime #6B8A0A box. On white or light grey. |
| `atticdb-mark-16.svg` | The light-ground version at 16px, for favicons and tabs. |
| `atticdb-mark-ink.svg` | All #16110E, for one-colour print. |

Rules:

- Bright lime #C8F03C is for dark grounds only. It is 1.3:1 on white and disappears. On light grounds the box is #6B8A0A, which keeps 3.6:1 or more.
- Do not rotate the mark, put it in a container shape, or add a door or window.
- Keep clear space of half the box width on every side.
- Write the name as `AtticDB` in text and `atticdb` in commands.

The studio and atticdb.com use these drawings. The studio draws them inline in `crates/atticdb/studio/index.html`.

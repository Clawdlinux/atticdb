# AtticDB brand assets

The mark is a roof with a box kept under it. The roof is the attic. The box is what you stored.

| File | Use |
|------|-----|
| `atticdb-mark.svg` | Default. Ink #0a0a0a roof, #1d5fbf box. On white or light grey. |
| `atticdb-mark-reversed.svg` | White roof, #7fa6e6 box. On near-black and other dark fills. |
| `atticdb-mark-16.svg` | The same drawing at 16px, for favicons and tabs. |
| `atticdb-mark-ink.svg` | All #0a0a0a, for one-colour print. |

Rules:

- Keep the roof in the ink colour of the surface and the box in that surface's 1 accent colour.
- Do not rotate the mark, put it in a container shape, or add a door or window.
- Keep clear space of half the box width on every side.
- Write the name as `AtticDB` in text and `atticdb` in commands.

The studio and atticdb.com use these drawings. The studio draws them inline in `crates/atticdb/studio/index.html`.

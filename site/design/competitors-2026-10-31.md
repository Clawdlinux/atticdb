# Agent Memory Competitive Landscape (As of October 31, 2026)

**Summary for AtticDB:** Every major VC-backed agent memory vendor (Mem0, Zep, Supermemory, Redis, Letta) centers on **LLM-extracted semantic/graph memory**, which requires LLM/embedding inference on write (sync or background worker) and does not guarantee `fdatasync` durability when acknowledging writes. Only local-first coding-agent tools (Claude Code's markdown files, Engram's SQLite+FTS5 Go binary) avoid mandatory cloud stacks, leaving a clear positioning gap for **AtticDB** as a single-binary Rust database with `fdatasync`-acknowledged turn/fact durability and zero-LLM-on-write latency. Visually, several competitors (Zep, Supermemory, Letta) have already pivoted away from dark purple SaaS toward light editorial/academic paper or monospace lab aesthetics.
